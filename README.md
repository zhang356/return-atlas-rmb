# 收益图谱 · 全球资产人民币收益比较

中文互动网页，比较同一笔本金投资 40 项资产的历史表现。支持 1 周、1 个月、3 个月、6 个月、年初至今、1 年、3 年和 5 年；计入分红再投资、历史人民币汇率和可编辑的境外盈利税务假设。

部署到 GitHub Pages，访客无需登录。公开仓库与标准 GitHub Actions 运行器支持免费托管，无需 Render 或行情 API 密钥。

## 数据如何更新

静态站点已发布到 https://zhang356.github.io/return-atlas-rmb/ 。当前自动更新尚未启用。准备好的每日更新配置需要额外的 GitHub workflow 授权才能上传；启用后在推送、手动执行及每日 UTC 22:23（北京时间次日 06:23）运行。计划任务可能延迟，长期无提交的仓库可能被 GitHub 停用计划任务，可在 Actions 中重新启用。

工作流获取雅虎财经已完成交易日的复权日线和汇率，校验后构建并发布静态网页。只有行情抓取步骤访问雅虎；访客浏览器从本站加载 `data/market.json`。网页“刷新数据”按钮重新读取已发布文件，不触发实时行情抓取。

上游失败时保留上次有效数据及真实抓取时间，并在页面标记刷新失败；不会将旧数据日期改成今天。GitHub Actions 缓存保留上次成功记录，仓库内 `src/snapshot.json` 作为缓存不可用时的初始数据（2026-10-17 获取）。网页显示实际收盘日期，距目标日期过远时显示“暂无数据”。2828.HK 较早历史不足的周期也显示“暂无数据”。

每日更新的静态站点不提供盘中实时行情。所有计算在访客浏览器完成，设置仅保存在本地浏览器。

## GitHub Pages 配置

当前使用公开仓库的 gh-pages 分支发布。启用自动更新后，Settings → Pages → Source 改为 GitHub Actions。自动发布工作流仅在发布任务中使用 `pages: write` 和 `id-token: write` 权限，构建任务只读取仓库，不需要额外密钥。

Pages 提供公开 HTTPS 地址，但这里没有承诺中国大陆所有运营商线路稳定可达，需要用实际网络测试。

## 本地构建与验证

需要 Node.js 22 或更新版本，无第三方 npm 依赖。

```sh
npm test
npm run update:data
npm run build:pages
node scripts/test-pages.mjs
```

更新行情需要联网；不执行 `update:data` 时，静态构建使用仓库内已验证的初始数据。`dist/` 是生成结果，不提交。可用任何静态服务器预览它。

备用 Node 服务器仍可用 `npm run build && npm start` 运行，但 GitHub Pages 不运行这个服务器。

默认 20% 税率仅为用户可调整的简化情景，不是报税建议。原币收益与人民币净收益均为累计回报，不作通胀调整。
