# 收益图谱 · 独立部署版

本版本独立运行，不依赖 ChatGPT Sites、ChatGPT 登录、访问令牌或 Google 字体。保留全部 40 项资产、中文界面、8 个持有周期、马赛克、分红复权、人民币汇率与可编辑税务假设。浏览器只向本站请求行情；服务器访问雅虎财经，失败时使用附带历史数据并提示日期。

## 在已有服务器上运行

需要 Node.js 22 或更新版本，无需安装第三方依赖。

```sh
node scripts/build.mjs
node server.mjs
```

默认监听 `0.0.0.0:8080`。可通过环境变量 `PORT` 和 `HOST` 更改。网站与 `/api/catalog`、`/api/history` 均允许匿名读取；没有登录页面或应用内 IP 白名单。

## 使用容器部署

```sh
docker build -t return-atlas .
docker run -d --name return-atlas --restart unless-stopped -p 8080:8080 return-atlas
```

部署到香港节点等独立服务器，在服务商侧开放对应端口；有域名时，由已有反向代理或托管平台为该应用配置 HTTPS，反向代理须同时转发 `/` 与 `/api/`。域名、云账号、实例与网络设置由所有者提供，本文件不包含账号或凭据。未创建付费资源。

## Render 免费试用方案

已附带 `render.yaml`，指定新加坡节点、免费实例、构建与启动命令。需要网站所有者注册并连接 Render，并提供该账号可部署的代码来源；尚未创建任何云端服务。Render 会分配公开的 HTTPS 网址，无需先购买域名。访客访问应用无需登录。

免费实例闲置 15 分钟后会休眠，再访问时需要等待启动；带宽与构建额度等限制以官方当前套餐为准。不要将此方案当作已验证的中国大陆网络承诺：部署后还需要以大陆实际线路测试首页与行情接口。

## 网络与数据边界

- 已去掉页面自动加载的 Google 字体。系统中文字体即可正常显示。
- 计算说明中的雅虎和税务网站链接仅在点击后打开，不参与页面加载。
- 上游行情仍需服务器具备访问雅虎财经的网络条件；浏览器不直接请求雅虎或旧 Sites 地址。
- 附带历史数据于 2026-10-17 获取，不代表实时行情；页面显示实际收盘日期。2828.HK 的较早历史不足，3 年、5 年等缺失周期显示“暂无数据”。数据过旧时也不估算收益。
- 不记录用户持仓或本金。用户设置仅保存在各自浏览器。
- 此包已具备独立运行条件，但尚未部署到新公网地址；未验证中国大陆电信、联通、移动线路可达性。
